# Adaptive Focus Studio

Project One proposal for Mobile App Development, Fall 2026. The proposed app is an offline Flutter focus-session planner with reusable presets, a pauseable timer, editable session history, local insights, and a transparent duration suggestion.

The [Word proposal](TeamMylesEziz_Project1_Proposal.docx) contains the team plan, SQLite data model, required smart-helper evaluation, Kanban milestones, and five annotated screen layouts. The [acknowledgment form](TeamMylesEziz_Acknowledgment_ToSign.pdf) is an unsigned draft; both team members must sign and date it before proposal submission. App development will begin after instructor-team approval.

Team: Myles Miller and Eziz Bagshiyev. Both are in the undergraduate pathway.
